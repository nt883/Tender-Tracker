# API Contract

Shared reference for data shapes. Update this file first, then tell the team, before changing any shape below.

## Report
```json
{
  "project_id": "abc123",
  "user_id": "xyz789",
  "description": "text the resident typed",
  "status": "pending",
  "created_at": "2026-09-26T12:00:00Z"
}
```

## Evidence
```json
{
  "evidence_id": "ev001",
  "report_id": "rep456",
  "file_url": "link or path to the uploaded file",
  "file_type": "image",
  "uploaded_at": "2026-09-26T12:00:00Z"
}
```
